# 知识中心使用指南

核对日期：2026-10-01。知识中心统一查找资料、Wiki、个人记忆和产品指南；资料上传、Wiki 编辑和记忆纠正仍在各自管理页面进行。

## 搜索与阅读

1. 登录后点击侧栏「知识中心」，进入「统一搜索」。
2. 在「知识范围」选择「我的知识」或已加入的团队，按需筛选来源类型，再输入至少两个字的关键词并点击「搜索」。团队范围不包含个人记忆，团队资料仍需满足共享权限。
3. 点击结果阅读来源。长文点击「继续阅读」；Wiki 等派生内容提供「查看原文」入口，沿依赖核对原始资料。依赖过多时按提示到 Wiki 查看完整记录。
4. 如果提示部分检索能力不可用或候选未展示，缩小问题范围、按来源分别搜索，或先检查资料加工状态。没有搜索结果不能证明资料中不存在相关内容。

检索结果是来源记录，不是事实认证。「存在分歧」表示还需核对原文及适用条件。来源删除、权限变化或版本更新后，旧引用可能无法继续读取；重新搜索以获取当前可用版本。

## 产品指南与个人资料

- 「浏览产品指南」提供只读的内置使用说明，支持分类、搜索和完整章节阅读，不占个人文档额度。聊天里的「产品指南」引用也会打开这里。
- 「管理资料」进入 Wiki：上传文本 PDF 或 UTF-8 TXT、查看加工状态、维护知识页面及版本。原文就绪与检索加工完成是不同状态；「重建知识」重建 Wiki 内容，不等同于重建检索索引。
- 「管理记忆」进入长期记忆：添加、编辑、固定或删除。出现「有一处需要你确认」时，比较相关记录并选择「纠正这条记录」，补充时间或情境后「保存纠正」。保存前双方保留，取消不修改内容。

## 提交来源反馈

打开搜索结果后，在「来源反馈」选择有帮助、内容有误、已经过期、缺少信息、引用不支持结论或可见范围有问题。填写可选的「补充说明」，再点击「提交反馈」。

反馈绑定当前来源及版本，进入后台复核队列。反馈不会自动改写资料或替换记忆，也不等于问题已经修复。

## 后台知识质量

管理员登录后，侧栏「知识质量」显示语义模型、版本和知识加工状态。语义模型显示「未启用」时，不能把任务就绪数量当作语义检索已经开启。

| 身份 | 可执行操作 |
| --- | --- |
| viewer | 查看加工状态与模型信息 |
| support / admin | 重试失败任务、查看待复核反馈、填写结论并完成复核 |
| admin | 另可重建当前检索索引，用于索引丢失或需要重新加工 |

「重试失败任务」重新排队失败任务；「重建当前检索索引」由后台逐步加工，可能产生模型用量。反馈每次显示最早的 100 条，处理完后重新打开页面查看下一批。完成复核只记录处理结论，内容修正仍需使用对应资料或记忆管理能力。

## 部署与能力边界

统一搜索、版本化引用和持久任务需要最新数据库结构，包括 PostgreSQL `000046_knowledge_projections` 或 MySQL `000035_knowledge_projections`，并启动后台 Worker。已有环境应执行全部待应用迁移，不能只挑最后一项。

Wiki 和记忆的内容向量由后台持久生成；未配置语义模型时保留词法检索，缺少索引或模型失败时报告降级。知识中心不是历史时点查询、视觉区域检索或自动事实证明工具。检索质量及大规模性能还需真实语料验收。

接口、索引规格、迁移和验证记录见[知识工程集成实现](KNOWLEDGE_ENGINEERING_IMPLEMENTATION.md)；产品指南的构建与维护见[内置项目知识库](PRODUCT_KNOWLEDGE.md)。
