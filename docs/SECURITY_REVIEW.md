## 公开状态与检查边界

本次修复通过本记录范围内的公开前检查。仓库的实时可见性与保护设置以 GitHub 为准。

Go 扫描仍提示 [GO-2026-5932](https://pkg.go.dev/vuln/GO-2026-5932)：涉及 `golang.org/x/crypto` 的旧 OpenPGP 包，目前没有修复版本。项目依赖图未导入这些包，扫描未发现可达调用；因此保留该记录，而不是将其错误表述为“全部依赖零漏洞”。

本次没有更改生产服务、重建运行中的容器、执行生产数据库迁移或自动替换现有部署凭据。开发用数据库/对象存储示例账号不得用于公网部署。容器操作系统、可选 Python `document` 依赖、移动端完整传递依赖及真实部署的权限边界需要独立检查；数据库集成测试需要专用测试实例。

历史提交和依赖更新分支并非受支持的安全发布版本。部署时使用最新已验证的默认分支，并重新构建镜像。发布源代码不等于现有运行服务已打补丁。
